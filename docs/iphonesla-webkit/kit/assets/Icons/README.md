# Icons

Lucide icons (ISC licence): `recycle.svg` is trade-in, drawn in `trade` ink (#1a7f45); `box.svg` (Lucide's package) is wholesale, drawn in `wholesale` ink (#2a2b30). These copies are for places that can only show an `<img>`. In the kit's components the same paths are inline with `stroke="currentColor"`, so they take the card's mark colour.

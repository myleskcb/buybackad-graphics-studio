# IconBadge

The service's mark in a glass disc, top right of a service card: a recycle mark for trade-in, a box for wholesale.

**You provide** `span.wk-badge` with a `title` naming the service, holding the inline SVG from Icons (stroke `currentColor`, so it takes `trade-card-mark` or `wholesale-card-mark`). The card's head leaves room for it on its own.

- One badge per card, always the service's own mark. The same recycle mark appears wherever a trade-in is in play: the Trade-in applied chip and the Use my trade-in row.

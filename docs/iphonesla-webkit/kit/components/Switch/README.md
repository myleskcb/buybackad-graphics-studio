# Switch

The iOS switch, in a row whose whole width toggles it.

**You provide** `label.wk-row.wk-row--toggle` holding an optional `.wk-icon`, `.wk-row__t`, and `span.wk-switch` with `input[type=checkbox][role=switch]` and `span.wk-switch__track`. On is `switch-on`; the knob's side says it too.

- The trade-in switch goes at the BOTTOM of checkout, after the summary, so people can turn the trade-in off; the shop only says "Trade-in applied".
- Say under it what turning it off does, and change that line when it is off ("You're keeping your iPhone 15 Pro").

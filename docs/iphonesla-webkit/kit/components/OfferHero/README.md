# OfferHero

The offer, big: the customer's own device, the amount in `credit`, and what it is for.

**You provide** `.wk-offer` with the device photo (it sits on the light `thumb` frame), `.wk-offer__label`, `.wk-offer__amount` with `data-wk-count` so it counts up from $0 when it comes into view (Celebration), and `.wk-offer__what` (the full spec line and grade). Follow it with what happens next and one block button that spends it ("Shop with $330 off").

Intentional addition: the offer step sits between the condition page and the shop.

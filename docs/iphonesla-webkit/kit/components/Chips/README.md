# Chips

Small labels that say a fact about a device or a price.

- `.wk-grade`: the condition grade before a spec line ("Grade A", "Good").
- `.wk-example`: on every made-up price or spec until it comes from the inventory. Remove it only with live numbers.
- `.wk-save`: under a shop price, what the trade-in takes off ("−$330 with your iPhone 15 Pro").
- `.wk-applied`: at the top of the shop when a trade-in is in play, with the recycle mark; it points to checkout, where the switch is.

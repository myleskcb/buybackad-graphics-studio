# Background photo manifest — Designer Library

One photo per template, dropped into `assets/bg/` with the EXACT filename.
Until a file exists, that template renders on its designed gradient fallback
(already shippable) — photos upgrade it to the full studio look.

**Global spec for every image:** 2160×2160 JPG (quality ~85), heavily
defocused / bokeh (shot blurry, not post-blurred text-safe), no text, no
logos, no people, dark-enough midtones that white type stays legible
(each template also adds its own scrim). Generate with the ORCHARD photo
engine or any image model — the scene + mood below is the prompt.
